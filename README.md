# Goswami Parivaar — App UI Prototype

High-fidelity clickable UI prototype for the Goswami Parivaar community app (MVP, SRS v1.1).

## View

- **Interactive prototype (start here):** open [`prototype.html`](prototype.html) — single entry point at the Splash screen; tap through the phone like a real app.
- **Screen catalogue with requirement coverage:** open [`index.html`](index.html)

## Status

Phase 1 (Core & Identity, 16 screens) is designed. Jobs & Events (Phase 2), Marketplace (Phase 3), Matrimony & Calls (Phase 4) and the Admin panel (Phase 5) follow.

Tech target for the real app: Kotlin Multiplatform + Compose Multiplatform, Ktor + PostgreSQL backend.
