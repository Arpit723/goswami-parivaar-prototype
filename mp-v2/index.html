Working rules for this set

· Each screen = standalone HTML, phone frame + requirements annotation table (same convention as v1).
· Requirements stay bound to every screen: discount 1–90 computed payable · stock pill semantics · seller XOR badges · statuses · gate rules.
· Product imagery = verified stock photos (17 URLs checked HTTP 200 today) — swappable for real photos later, layout unaffected.
· Old v1 set stays live at marketplace.html until v2 is complete.
· Deployed to GitHub Pages with the rest of the prototype after each screen batch.
